#  NSAP Eligibility Prediction using Machine Learning

This project automates the classification of applicants into appropriate sub-schemes under the **National Social Assistance Programme (NSAP)** using machine learning. It is designed to support fair, efficient, and scalable welfare delivery, especially for marginalized communities.

---

## 🚀 Project Overview

- Predicts NSAP sub-scheme eligibility using Decision Tree models  
- Built and deployed on **IBM Cloud Lite** using Watson Studio and SPSS Modeler  
- REST API enabled for real-time predictions  
- Designed with fairness, accessibility, and low-resource deployment in mind

---

## ⚙️ Technologies Used

- IBM Watson Studio  
- SPSS Modeler  
- Python (for preprocessing and API testing)  
- REST API (for deployment)  
- Cloud Object Storage  
- GitHub for version control

---

## 📊 Model Performance

- Accuracy: ~92% on test data  
- Confusion Matrix and ROC Curve included  
- Bias audit performed across gender and region attributes  
- Output structured for easy integration with government dashboards

---

## 🔮 Future Scope

- Model expansion to other welfare schemes  
- Fairness and bias audits
